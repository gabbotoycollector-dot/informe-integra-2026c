# Informe Integra 2026C

Informe de la plataforma Integra 2026C y propuesta del semillero SamaLab by CUN.
Programa de Diseño Gráfico · CUN, regional Santa Marta · noviembre de 2026.

Sitio estático (HTML, CSS e imágenes). No necesita compilación.

## Publicar en Cloudflare Pages

1. Sube el contenido de esta carpeta a un repositorio de GitHub (los archivos en la raíz, no dentro de otra carpeta).
2. En Cloudflare: **Workers y Pages → Crear → Pages → Conectar a Git** y elige el repositorio.
3. Configuración de compilación:
   - Framework: **Ninguno**
   - Comando de compilación: *(vacío)*
   - Directorio de salida: **/**
4. **Guardar e implementar.**
